# مهام

منظّم شخصي بالعربي للموظفين وكل من يدير يوم مزدحم: مهام، تقويم، تذكيرات، وملاحظات.

- **اليوم:** ملخص بالأرقام، وشريط اليوم (كل المواعيد من ٦ص إلى ١٢م مع الوقت الحالي)، والجدول، والمهام بدون وقت، والمتأخرة.
- **التقويم:** شهر كامل مع نقاط ملونة حسب القائمة، وجدول اليوم المختار.
- **المهام:** كل المهام حسب القائمة (العمل، شخصي، البيت، الصحة).
- **الملاحظات:** بحث، تثبيت، وحفظ تلقائي.
- **التذكيرات:** قبل الموعد بالوقت المختار، كإشعار داخل التطبيق مع تأجيل أو إنهاء.

## الملفات
- `src/app.html` — مصدر التطبيق (صفحة واحدة بدون مكتبات)
- `index.html` — النسخة الكاملة (`node scripts/build.mjs`)
- `scripts/shoot.mjs` — تصوير كل الشاشات بـ Playwright

## الخط
يستخدم خط «ثمانية» (Sans وSerif Display) إذا كان مثبّت على الجهاز. ملفات الخط **غير مضمّنة** لأن رخصته للاستخدام الشخصي فقط. للتحميل: font.thmanyah.com
