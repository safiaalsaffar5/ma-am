# مهام

تطبيق مهام يومية بالعربي، يركّز على مهمة وحدة كل مرة.

- `src/app.html` — مصدر التطبيق (صفحة واحدة: HTML + CSS + JS بدون مكتبات)
- `index.html` — النسخة الكاملة الجاهزة للفتح في المتصفح (`node scripts/build.mjs`)
- `scripts/shoot.mjs` — يصوّر كل الشاشات (آيفون وديسكتوب، نهاري وليلي، فاضي ومليان) بـ Playwright

## نظام التصميم
- خط IBM Plex Sans Arabic، سلّم 1.25 (12 → 39)، وزنين فقط 400 و600
- درجات 50–900 للون المميز (أخضر النخل) وللرمادي الدافئ، بتباين AA
- مسافات 4/8/12/16/24/32/48/64، ظلال sm/md/lg مركّبة من طبقتين
- حركة: ease-out للدخول، ease-in للخروج، spring للعناصر التفاعلية

البيانات تنحفظ في المتصفح، وتتزامن بين أجهزتك لما يكون التطبيق مفتوح كـ Artifact في claude.ai.
